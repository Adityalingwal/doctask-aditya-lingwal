# sample-projects

One folder per project lives here. This is the folder the Add-project box
lists on the screen.

This folder starts **empty**. The application never creates a project on its
own: a person makes a folder here first, then creates the project over it —
through the screen's Add-project box or the MCP `create_project` tool.

## The Helpline AI corpus

The sample documents live in `sample-documents/helpline-ai/` — see
[its README](../sample-documents/helpline-ai/README.md) for what they contain
and the order to copy them in. Copy them into a folder created here, for
example `sample-projects/helpline-ai/`, one at a time or in pairs. Each batch
you copy in starts one run. Documents copied here are git-ignored.
